# X Post Watch context

`config/watches.json` is the single source of profile behavior. Keep `id` stable because it namespaces runtime cursor state. `twitter_emoji` and `emoji` use Discord custom-emoji markup such as `<:twitter:1531672630602498129>` and `<:kutekians:1531673483459821729>`. Profiles intentionally include a declarative `discord_channels` list, source URL, display name, every forwarding control, media setting, `enable_llm_title`, `enable_llm_summary`, `enable_llm_routing`, `enable_llm_relevance_filter`, `additional_prompt_instruction`, `thread_handling`, enablement, and a poll cap so adding a profile does not need a code change.

RSSHub's VPS user timeline route works with its private X auth token. The watcher only reports sanitized errors such as `RSSHub X feed HTTP 403: authentication rejected`. Do not inspect, copy, log, or commit the token. A source failure waits for the next scheduled minute, avoiding retry pressure.

`enable_llm_title`, `enable_llm_summary`, `enable_llm_routing`, and `enable_llm_relevance_filter` are per profile and default to `false` for every new profile. When any is `true`, the scanner stays responsible for fetching, filtering, deduplication, durable state, final rendering, media, heartbeat, and Discord delivery. Hermes is responsible only for the closed relevance decision and required source-grounded Indonesian fields submitted through `scan.py submit-analysis`. A title-only profile retains the raw post below its new title and muted writer byline. A routing profile sends exactly once to the configured `discord_channels` entry matching the returned key. Route by central thesis, not proper nouns: market-wide leverage, derivatives, liquidity, valuations, investor positioning, bubbles, and broad AI-cycle risk are macro even when companies or ETFs appear. Use `id_stock` only for IDX-listed company theses, and `us_stock` only for NYSE- or Nasdaq-listed security theses including ADRs. For an unknown or ambiguous central ticker, use Yahoo Finance, then Serper, then Brave Search to identify only its issuer, exchange, listing country, and exact exchange ticker. Lookup metadata may affect the title ticker and route but must never add other outside facts to the source-grounded title or summary. Inconclusive or conflicting results fall back to macro without guessing. A direct company thesis outside the Indonesian or US-listed universes also falls back to macro until a dedicated channel exists. Stock-route titles start with the exact exchange ticker. Summaries state the analysis directly, without third-person narration about Ricky or the writer. Relevant content includes substantive economy, business, capital-markets news, analysis, opinion, market education, and investing views; surveys, promotions, greetings, personal updates, event invitations, generic engagement, and unrelated random posts are discarded without delivery. Direct ticker disclosures, earnings, corporate actions, dilution, rights issues, private placements, and `#RangkumKeterbukaanInformasi` / `#RangkumReport` posts are deterministic always-relevant exceptions, so a false LLM decision is rejected and retried. Summary mode retains a truncated ordinary quoted post. Ignore standalone X Articles completely; an authored Article quote renders only its compact three-line card (`author`, `(Article)`, and `Read Article on X`) plus its cover or preview media, never Article body text. A quoted post's first ordinary source URL becomes a `Read source` anchor and ends the rendered quote, so the raw URL is never exposed or split.

`thread_handling.self_chain` merges up to 20 same-author quote or reply continuations from the prior four hours available in the timeline. Its bounded thread-settling window is a maximum, not a per-continuation delay: an observably multi-post chain in one poll proceeds immediately, while a lone post can be held for at most the configured window from its first observation. New continuations extend the collected chain but never restart that maximum window. `disabled` bypasses holding and chain collection, so each eligible post is immediately ready for analysis or delivery. Combined content, not merely its final short continuation, is sent to the LLM. Thread media preserves root-to-latest order before external quote media. Long source text is split semantically, while `View on X` links and quote blocks remain whole.

`additional_prompt_instruction` is a trusted, optional profile setting normalized to one line and capped at 800 characters. It refines relevance or presentation for one durable account behavior. It is never derived from source text and does not override disclosure safeguards, route validation, or common LLM rules.
