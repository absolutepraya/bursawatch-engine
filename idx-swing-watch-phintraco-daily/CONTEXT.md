# IDX Swing Watch

This context names the Phintraco Sekuritas recommendations and alert representations handled by IDX Swing Watch.

## Language

**Phintraco Daily Event**:
One individual, source-authored Phintraco Telegram message handled by IDX Swing Watch. A Phintraco Daily Event is either a Swing Call, a Swing Outcome Reminder, or a Swing Plan Status Reminder.
_Avoid_: signal, post, notification

**Swing Outcome Reminder**:
An individual Phintraco `Reminder` message for one ticker that reports a first, numbered, or all-target outcome, a stop-loss outcome, or a target update accompanying a target-achievement outcome. It is not a Swing Call because it does not create a new Entry, Stop-loss, and Target recommendation.
_Avoid_: Swing Call, malformed buy recommendation, weekly idea

**Swing Plan Status Reminder**:
An individual, source-authored Phintraco message for exactly one IDX ticker that confirms a prior trading plan remains active or presents an `On support` setup. A source-marked update accepts `on support`, `on track`, `still on plan`, `still on track`, `still in line`, `still inline`, the source typos `on trac` and `still inilne`, `still hold`, `keep on plan`, `keep in plan`, and `trading plan sebelumnya masih berlaku`, allowing only punctuation and whitespace variation. `on trac` renders as `on track`; `inilne` renders as `inline`. A footerless `TICKER on track` or `TICKER on trac` reply is eligible only when it replies to a parsable `BUY` or `STATUS` event for the same ticker. Other footerless updates are excluded. A message with any recognised target or stop-loss outcome is a Swing Outcome Reminder rather than a Swing Plan Status Reminder.
_Avoid_: Swing Call, Swing Outcome Reminder, inferred conviction

**Swing Call**:
An individual Phintraco buy recommendation for one IDX ticker that contains an entry, stop-loss, and at least one target. Trading Buy, Buy on Support, and Speculative Buy are Swing Call subtypes.
_Avoid_: signal, stock tip, weekly idea

**Outcome**:
The source-authored result or progression stated by a Swing Outcome Reminder, such as first target achieved, a numbered target achieved, all targets achieved, or stop-loss hit. One reminder may contain more than one source outcome; the watcher preserves them without resolving a conflict.
_Avoid_: inferred performance, generated execution status

**Call Subtype**:
The recommendation label assigned by Phintraco to a Swing Call: Trading Buy, Buy on Support, or Speculative Buy.
_Avoid_: signal type, strategy score

**Source Event Identity**:
The immutable Telegram source-message ID of a Phintraco Daily Event. Delivery deduplicates by this identity; a Telegram edit does not create a new event.
_Avoid_: ticker identity, current message text

**Signal Provider**:
The organization that authors a Phintraco Daily Event. Its Discord alert heading starts with the server custom emoji `:phintraco:`; the initial provider is Phintraco.
_Avoid_: group, source group, broker tag

**Swing Alert**:
A concise presentation of one Swing Call that preserves only source-provided facts, rationale, Telegram source-post timestamp, and attribution, followed by its Source Chart when one is available.
_Avoid_: analysis, generated recommendation, scored alert

**Swing Outcome Reminder Alert**:
A concise Discord presentation of one Swing Outcome Reminder. It has the level-three `:phintraco: REMINDER` heading, preserves the source Outcome and any target updates, then gives the Telegram source-post timestamp and attribution, followed by its Source Chart when available.
_Avoid_: BUY alert, SELL alert, generated trade instruction

**Swing Plan Status Reminder Alert**:
A concise Discord presentation of one Swing Plan Status Reminder. It has the level-three `:phintraco: HOLD` heading, then `**Status:**` with the source status and `:hold:` directly beside that value, followed by every source-provided `**Entry:**`, `**Stop-loss:**`, and numbered `**Target:**` values. It then gives the Telegram source-post timestamp under `**Status date:**` and `**Source:**`. It is followed by its Source Chart when available or `**Chart:** Unavailable from source` when no chart is attached to that same source message.
_Avoid_: BUY alert, REMINDER alert, generated trade instruction

**Source Message Link**:
The public Telegram permalink for the immutable source-message ID of a Phintraco Daily Event. The provider name `Phintraco Sekuritas` in an alert’s existing `**Source:**` footer is its Markdown anchor text, so the link adds no line or standalone label.
_Avoid_: a separate Open Message line, a link to a search result, a nearby Telegram post

**Source Chart**:
Chart media attached by the Signal Provider to the same source message as a Phintraco Daily Event. It is optional, is never inferred from a nearby post, and is never generated by IDX Swing Watch. The deterministic harness proves source-message identity, not the visual ticker rendered within provider-authored image pixels.
_Avoid_: replacement chart, adjacent image

**Weekly Swing Bundle**:
A multi-stock Phintraco recommendation published as a text bundle with a separate PDF. It is not a Swing Call in this context and is deferred from IDX Swing Watch.
_Avoid_: swing call, individual call
