# RSSHub service

RSSHub is the shared, VPS-hosted feed service used by BursaWatch watchers and
by the Personal repository's US ETF cron. Its compose definition, credentials,
cookies, proxy configuration, and runtime data remain VPS-owned and are not
copied into this repository.

This directory deliberately contains documentation only for the initial split.
Any future source import must begin with a reviewed source-versus-VPS diff that
excludes secrets and runtime data.
