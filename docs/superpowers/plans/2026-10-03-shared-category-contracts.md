# Shared Category Contracts Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `subagent-driven-development` or `executing-plans` to implement this plan task by task. Steps use checkbox (`- [ ]`) syntax for tracking. Read the spec first. Native execution is recommended for this coupled change and the user's credit preference.

**Goal:** Share source-faithful Macro, Industry, and Swing presentation across owners, with optional image context after text eligibility and unchanged delivery reliability.

**Architecture:** Extend `lib-news-format` with composable writing instructions, and `lib-swing-format` with typed source-plan presentation. Put verified optional image preparation in the existing Source Media client library; owners expose a claim-bound tool in their current agent workflow. Owners retain semantic eligibility, routing, source interpretation, frozen delivery state, and receipts; the Board retains deterministic lifecycle decisions.

**Tech Stack:** Python and pytest; standard-library shared helpers; existing Hermes agent/image viewer, Source Inbox, Source Media client, and Discord Delivery client. No new model dependency, OCR stage, service, database migration, or external research integration.

**Spec:** [Shared category contracts](../../specs/2026-10-03-shared-category-contracts.md), with [boundary ADR](../../adr/0032-shared-category-contract-boundaries.md).

**Baseline:** `6623dd4aaadc7904d0c6274e228a66ca9edcf901` on `t3code/shared-category-contracts`, matching fetched `origin/main` when this plan was written. This is a separate follow-up to PR #48. No current production claim is made.

## Global Constraints

- Adopt category guidance in this order: Macro, Industry, then Swing. Tasks 3 and 4 provide the agreed additional context before Swing adoption.
- Common writing rules belong in the shared component. Adapters retain source interpretation, identities, relevance requirements, typed submissions, and destination selection.
- Report directly in factual Bahasa Indonesia. Preserve meaningful attribution for research, estimates, forecasts, guidance, and interpretation.
- Prefer two short paragraphs for longer summaries; a short or cohesive item may remain one paragraph. No fixed style thresholds or blocking style gates.
- Preserve periods, units, actual versus forecast/consensus/prior/revised figures, YoY versus MoM, and percent versus percentage points.
- Industry company impacts require supplied exposure evidence and a direct connecting mechanism. Unsupported implications are omitted while eligible news remains deliverable.
- Images are additional context after text eligibility. No new inspection for ineligible text or image-only news; no scanning every incoming image or mandatory second model.
- Optional image failure falls back to supported text without holding delivery or retrying merely for image context. Specialized Swing PDF/image intake and required source-media contracts remain intact.
- Entry, Stop-loss, and Target 1 always appear on source-plan cards, with `-` for missing base values. Omit absent additional targets/stops; preserve supplied numbering, ranges, comparators, dates, status, and conditions.
- The source-analysis LLM recognizes approved Swing synonyms. `Support utama: 260` means `Stop-loss: <260`; arbitrary support does not. Preserve explicit source comparators.
- Qualifying complete Phintraco remains Primary plan; Kelas GTW remains Supporting setup; X/social remains Chart context.
- Only active Primary plans receive the existing 16:30 WIB close check and exact-plan/session 17:00 WIB unavailable-price retry. No lifecycle, calendar, comparison, schedule, or destination change.
- Preserve frozen messages and destinations verbatim on retries, plus item order/deduplication, source identities, operation keys, payload digests, receipts, and retry identities. No replay, backfill, repricing, or re-analysis on delivery retries.
- Keep inputs/results closed and backward compatible. Preserve required-media, source-grounding, and transport bounds while removing generic style rejection.
- Read package `AGENTS.md` and its root contract before edits. Focused tests, affected package suites, then `bash scripts/test-all`. Tests use isolated fixtures/fake clients, without live posts or production state.
- Implementation, PR creation, production release, scheduler operations, and cross-machine writes are separate authorizations. Do not read or modify `CONTEXT.md`.

## Review Focus

1. A Tuntun Industry candidate has route `macro_news`: owner source kind must select Industry guidance while destination and feed category remain unchanged (Task 2).
2. An image request races a lease change or source correction, or contains a wrong digest: expose no stale bytes and complete eligible news from text (Tasks 3 and 4).
3. Image-only/ineligible news, or a mixed news and specialized Swing event: ordinary news must not gain an upfront image/OCR pass; required specialized source-media behavior must survive (Task 4).
4. TP2 appears before TP1, TP1 is missing, or an entry has a midpoint elsewhere: retain numbered targets and the original range; an optional bad normalization must not block a grounded summary (Tasks 5 and 6).
5. A pending delivery already has a receipt or a partially sent legacy Swing message: preserve exact remaining bytes, destination, and operation identities after formatter adoption (Tasks 4 and 6).
